# Security policy

Electromoon is an experimental research runtime. It has not undergone an
independent security review, and it does not claim Electron, sandbox, file
consent or packaging compatibility.

Do not use this preview for untrusted content or production data.

Report a vulnerability privately through GitHub Security Advisories. Do not open
a public issue for an exploitable bug. Include the affected command, commit,
platform/WebView versions and a minimal reproducer. Reports about the Node
reference CLI, the native runtime or the native host should say which one was
exercised.
