# Production SBOM (EP-24 partial)

Status: **partial**. `scripts/app-sbom.cjs` emits deterministic CycloneDX 1.5
JSON from the lock-driven production closure. It is not a signed artifact,
license report or provenance attestation.

## Inputs and rules

- input: `compatibility/apps/*/production-closure.json` with schema 1 and PASS
- every component must have a `node_modules/...` path, name and version
- absolute paths, `..`, backslashes and duplicate package paths are rejected
- npm `sha512-<base64>` integrity is converted to a 128-character SHA-512 hex
  hash; missing/malformed integrity omits `hashes` rather than inventing one
- components are sorted by `bom-ref` for deterministic output
- the app component and build hashes are recorded in `metadata.properties`

The SBOM contains production packages from the closure only. Dev packages,
Node itself, native host binary, app assets and OS WebView are not silently
included or excluded; those need separate packaging/SBOM ownership.
